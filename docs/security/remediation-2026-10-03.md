## Additional corrections

Native push teardown retires the registration, removes listeners and delivered notifications, attempts token deletion and unregisters before Firebase identity teardown. A generation and UID check reject delayed callbacks from an earlier registration. Best-effort native cleanup has a timeout so offline push persistence cannot indefinitely prevent authentication teardown. A runnable adapter regression covers registration for one user, logout, registration for another and a delayed old callback. Actual FCM delivery, already queued operating-system notifications and device behavior require separate evidence.

The Cloudflare deploy job selects the existing `Production` or `Preview` environment. Its preview step references only `CLOUDFLARE_PREVIEW_API_TOKEN`; an absent token skips publication without emitting a deployment URL or claiming successful publication. Android publication requires all signing inputs, restrictive temporary file permissions and `assembleRelease`; it uploads only the release artifact. Release signing was not executed locally.

## Dependency advisories

Compatible security updates cover Next.js and its lint plugin, DOMPurify, js-yaml, undici, brace-expansion, gRPC and the Functions-only fast-uri dependency. Root and Functions lockfiles are updated. The existing OpenNext response adapter patch remains active.

Registry audit results moved from 27 root advisories (1 critical, 12 high, 8 moderate, 6 low) to the single high advisory mitigated below. The separate Functions audit moved from 6 advisories (3 high, 2 moderate, 1 low) to zero. These are dependency-graph audit results, not counts of independently exploitable application vulnerabilities.

The registry still reports [GHSA-vfj7-8cjw-p6xm](https://github.com/advisories/GHSA-vfj7-8cjw-p6xm) for `braces@3.0.3`, a development-tool dependency without a published corrected version at verification time. A pnpm patch limits parser nesting and recursive compile, expand and stringify AST traversal. The regression rejects deeply nested string and AST inputs and preserves ordinary glob expansion. The package version remains affected in registry metadata; this is a tested local mitigation, not a claim of a clean root registry audit. Remove the patch only after reviewing an upstream fix and rerunning its regression. This patch addresses the cited stack-exhaustion issue, not arbitrary expansion cardinality or other undiscovered defects.
